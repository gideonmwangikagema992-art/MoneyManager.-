# MoneyManager UI/UX Design

## Design Philosophy

MoneyManager should feel simple, fast, and natural.

The app should help users manage money without making financial tracking feel like a burden.

The main goal:

"Record money quickly, understand money clearly."

---

# Home Screen Design

## Primary Display

The main number displayed on the home screen is:

## Available Spending Money

This represents money the user can actively spend.

Includes:
- Cash
- Everyday card balance
- Mobile wallets

Example:

Available Spending Money

QAR 850

Cash: QAR 150
Card: QAR 700

---

# Protected Total Wealth

The user's complete financial picture is protected.

It includes:

- Bank savings
- Investments
- Crypto
- Long-term accounts
- Other assets

The total wealth is hidden by default.

User must tap and enter security PIN to view.

---

# Main Currency System

The user chooses a main currency.

All balances are converted and displayed using this currency.

Example:

Main Currency:
QAR

Other currencies:

KES 10,000
USD 200

Displayed:

Total value in QAR

Original currencies are still stored.

---

# Dashboard Sections

Home screen contains:

1. Available Spending Money

2. Today's Money In

3. Today's Money Out

4. Recent Transactions

5. Add Transaction Button

---

# Add Transaction Flow

User taps:

+ Add Transaction

Options:

- Income
- Expense

---

## Transaction Information

Required:

- Amount
- Category
- Account

Automatic:

- Date
- Time

Optional:

- Notes
- Description
- Receipt image

---

# Multiple Transaction Mode

Users can record several transactions quickly.

Example:

Shopping trip:

1. Groceries
2. Fuel
3. Coffee

Continue button allows adding multiple transactions before finishing.

---

# Save Behaviour

After saving:

1. Show confirmation message.

Example:

"Expense saved ✅"

2. Return to Home Screen.

3. Update balance and recent transactions immediately.

---

# UX Principles

MoneyManager follows:

## Fast

Common actions should require few taps.

## Clear

Users should always understand:

- Where money is
- Where money went
- What changed

## Private

Sensitive financial information should be protected.

## Simple

The app should be easy even for first-time users.
